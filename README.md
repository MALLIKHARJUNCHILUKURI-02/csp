# Gas Leakage Detector using Arduino Uno

## 📌 Project Overview
Gas leakage accidents are a common issue in both residential and industrial settings. This project focuses on designing and implementing a **Gas Leakage Detector** using an **Arduino Uno** and an **MQ-6 gas sensor** to continuously monitor **LPG gas levels** in the air. The prototype aims to provide an early warning system to prevent potential fire hazards and explosions.

## 🚀 Features
- **Real-time gas monitoring** with MQ-6 sensor.
- **Visual and audible alerts** (LED indicators & buzzer activation).
- **Low-cost and portable design**.

## 🛠️ Technologies Used
- **Arduino Uno** – Microcontroller for processing data.
- **MQ-6 Gas Sensor** – Detects LPG gas concentration.
- **Buzzer & LED Indicators** – Alerts users in case of leakage.
- **LCD Display** – Shows gas concentration levels.

## 🎯 How to Run the Project
1. **Assemble the Components:**
   - Connect **MQ-6 sensor, Arduino Uno, buzzer, LED indicators, solenoid valve**, and **ESP8266 module** as per circuit diagram.
2. **Upload the Code:**
   - Use **Arduino IDE** to upload the sketch to Arduino Uno.
3. **Test Gas Detection:**
   - Simulate a gas leak by bringing an LPG source near the sensor.
   - Observe **buzzer, LED alerts, and solenoid valve operation**.
